Barcode numbering rule

Changing this re-previews the numbers; nothing changes until you confirm.
  • Quantity = 1 → barcode number = Sr. no. padded to fixed digits (e.g. 000001, 020989)
  • Quantity > 1 → one unique barcode per unit: 000412-1, 000412-2, 000412-3 …, each carrying the same linked panel information.
  • Barcode type: Code 128 (reads on any phone camera or handheld scanner).
